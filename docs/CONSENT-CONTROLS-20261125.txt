DEFERRED BOOTSTRAP / EXTERNAL CMP CONFIGURATION READINESS
The conditional bootstrap is prepared, not deployed. The current hosted
CookieYes provider rule assigns googletagmanager.com to Advertisement, which
blocks an analytics-only visitor's deferred GTM and potentially gtag script.
The documented data-cookieyes="cookieyes-analytics" annotation alone did not
resolve the existing broad provider rule. No ad permission was granted to work
around it, and no browser/extension/network block was bypassed.

An isolated response-interception harness simulated only changing that provider
category from advertisement to analytics. With that proposed configuration, the
full desktop/GPC/DNT mobile matrix passed: zero Google bootstrap before choice
or after rejected reload; one bootstrap per granted page; no duplicate after
withdrawal/re-enable; all previous choice/persistence/cookie-cleanup cases pass.
All Google delivery, collectors and provider/form mutations remained blocked.
The REMOTE COOKIEYES ACCOUNT WAS NOT CHANGED by this simulation.
Actual hosted category correction and matched Google publication/live QA remain
required before source activation. Native ad-cookie categories and strict
Google Ads holds must remain separate and denied by analytics-only consent.
